# SPEC.md

## 1. Requirement
Я пользователь. Надо, чтобы задачи с пустым названием (состоящим только из пробельных символов, включая невидимые) не сохранялись при создании или переименовании.

## 2. Acceptance tests (R1-R3)
*   **R1 (Создание и переименование):** Если название состоит только из пробелов, табуляции (`\t`), неразрывного пробела (`U+00A0`) или невидимого пробела (`U+200B`), задача не должна создаваться или переименовываться. Должна показываться ошибка «Название не может быть пустым».
*   **R2 (Фильтрация списка):** Унаследованная пустая задача (id: 3 с названием "   ") не должна отображаться в списке «Открытые».
*   **R3 (Счётчик):** Счетчик «Открытых» не должен учитывать унаследованную пустую задачу (должен показывать 1, а не 2).
*   **R4:** Тесты (в `src/tasks.test.ts`) покрывают все случаи выше, включая вариант с `U+200B`.

## 3. Non-goals (Что мы НЕ делаем)
*   Не меняем дизайн и верстку приложения.
*   Не добавляем новые фичи (например, удаление задач).
*   Не переписываем хранилище данных.

## 4. Files in scope (Файлы для изменений)
*   `src/tasks.ts` (логика)
*   `src/App.tsx` (экран и вывод ошибки)

## 5. Definition of done (Критерии готовности)
*   `npm test` проходит успешно (зеленый).
*   `npm run build` проходит без ошибок типов.
*   На экране не отображаются пустые строки, счетчик показывает правильное число.
